Excel Data Exploration & Analysis – Product Dataset

📌 Project Overview

  This project demonstrates foundational **Data Analyst skills using Microsoft Excel**. The objective is to perform basic data exploration, apply Excel formulas and functions, categorize product data, perform conditional calculations, and extract useful information from text fields.

  The project uses a product dataset containing information such as **Product ID, Product Name, Brand Name, Quantity, Category, and Price.

  This project is part of my Data Analytics learning journey and portfolio development**, with a focus on building practical skills in Excel-based data analysis.

🎯 Objectives

The main objectives of this project are to:

* Explore and summarize product data using Excel.
* Calculate basic statistical measures.
* Apply logical functions for data categorization.
* Perform conditional aggregation and counting.
* Extract information from Product IDs using text functions.
* Build a structured Excel analysis that can be presented as part of a Data Analyst portfolio.

 📊 Dataset Description

The dataset contains information about different products.

Dataset Attributes

| Column       | Description                        |
| ------------ | ---------------------------------- |
| Product ID   | Unique identifier for each product |
| Product Name | Name of the product                |
| Brand Name   | Brand associated with the product  |
| Quantity     | Quantity of products               |
| Category     | Product category                   |
| Price        | Price of the product               |

 🛠️ Excel Functions Used

The following Excel functions were applied in this project:

| Function  | Purpose                                             |
| --------- | --------------------------------------------------- |
| `SUM`     | Calculate total price                               |
| `COUNT`   | Count products                                      |
| `AVERAGE` | Calculate average price                             |
| `MIN`     | Find minimum price                                  |
| `MAX`     | Find maximum price                                  |
| `IF`      | Categorize products by price                        |
| `SUMIF`   | Calculate conditional total                         |
| `COUNTIF` | Count records meeting a condition                   |
| `LEFT`    | Extract characters from the beginning of Product ID |
| `RIGHT`   | Extract characters from the end of Product ID       |
| `MID`     | Extract characters from the middle of Product ID    |
